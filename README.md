# Lotus Beauty Parlour — Plain HTML/CSS/JavaScript

Static portfolio website for Lotus Beauty Parlour, Dumraon, owned and operated by Kanchan Mishra.

## Files
- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `pricing.html` — Pricing
- `gallery.html` — Gallery
- `bridal-packages.html` — Bridal packages
- `appointment.html` — Appointment / enquiry form
- `contact.html` — Contact + map
- `admin.html` — Static admin dashboard prototype
- `styles.css` — Shared CSS
- `script.js` — Shared JavaScript
