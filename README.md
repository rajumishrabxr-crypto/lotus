# Lotus Beauty Parlour — Plain HTML/CSS/JavaScript

Static portfolio website for Lotus Beauty Parlour, Dumraon, owned and operated by Kanchan Mishra.

## Files
- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `pricing.html` — Pricing
- `gallery.html` — Gallery
- `bridal-packages.html` — Bridal packages
- `appointment.html` — Appointment / enquiry form
- `contact.html` — Contact + map
- `admin.html` — Static admin dashboard prototype
- `styles.css` — Shared CSS
- `script.js` — Shared JavaScript

## Run
No Node.js, React, or build step is required. Open `index.html` in a browser, or serve the folder with any static web server.

## Replace before launch
Edit `script.js` to replace:
- Dummy WhatsApp number: `919999999999`
- Dummy phone number: `+91 99999 99999`
- Dummy Instagram URL: `https://instagram.com/lotusbeautyparlour`

Also replace placeholder pricing, testimonials, opening hours, map query, and the Unsplash images with the parlour's approved information/assets.

## Notes
The appointment form is intentionally simple: it validates the browser form and then opens WhatsApp with the customer's details. The `admin.html` page is a UI prototype only and does not connect to a database or authentication system.
